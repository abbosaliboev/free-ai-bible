## ⚡ Guide de démarrage rapide

**Lancez une application IA entièrement fonctionnelle en moins de 5 minutes :**

### Option A — LLM cloud en 60 secondes

```bash
# 1. Obtenez votre clé API Groq gratuite sur console.groq.com
# 2. Installez le SDK
pip install groq

# 3. Exécutez votre première requête
python -c "
from groq import Groq
client = Groq(api_key='YOUR_KEY_HERE')
response = client.chat.completions.create(
    model='llama-3.3-70b-versatile',
    messages=[{'role': 'user', 'content': 'Hello! What can you do?'}]
)
print(response.choices[0].message.content)
"
```

### Option B — Stack IA locale complète en 3 commandes

```bash
# 1. Installez Ollama
curl -fsSL https://ollama.com/install.sh | sh

# 2. Téléchargez un modèle (Llama 3.2 — fonctionne avec 8 Go de RAM)
ollama pull llama3.2

# 3. Commencez à discuter
ollama run llama3.2
```

### Option C — Génération d’images gratuite en 2 minutes

```bash
pip install diffusers transformers torch accelerate

python -c "
from diffusers import StableDiffusionPipeline
pipe = StableDiffusionPipeline.from_pretrained('runwayml/stable-diffusion-v1-5')
pipe.to('cpu')
image = pipe('a futuristic developer workspace').images[0]
image.save('output.png')
print('Image saved to output.png!')
"
```

> 💡 **Conseil :** Consultez le dossier [`/scripts`](./scripts/) pour les scripts d’installation en un clic correspondant à chaque option ci-dessus.
> Consultez le dossier [`/templates`](./templates/) pour des modèles d’applications complets prêts à être copiés et utilisés.
