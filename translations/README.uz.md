## ⚡ Tezkor boshlash

### A variant — Bulut LLM (60 soniyada)

```bash
pip install groq
python -c "
from groq import Groq
client = Groq(api_key='SIZNING_KALITINGIZ')
r = client.chat.completions.create(
    model='llama-3.3-70b-versatile',
    messages=[{'role': 'user', 'content': 'Salom! Nima qila olasiz?'}]
)
print(r.choices[0].message.content)
"
```

### B variant — To'liq mahalliy AI (3 buyruq)

```bash
curl -fsSL https://ollama.com/install.sh | sh
ollama pull llama3.2
ollama run llama3.2
```
